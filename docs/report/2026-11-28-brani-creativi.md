# Report: i brani dei generi creativi (28/11/2026)

Tre giri di lavoro, ognuno partito da un giudizio all'ascolto.

## 1. «I brani ripetono troppo»
| | |
|---|---|
| Causa | spartiti del modello YuE2 con 74-97% di battute ripetute, spesso 1-3 accordi; compositore di riserva con materiale fisso per genere |
| Intervento | livello di *estro* per genere e nuovo compositore ([progetto](../superpowers/specs/2026-11-28-estro-design.md)) |
| Misura | ripetizione mediana 11% |
| Prova | «Asfalto Rovente»: 209 s su 210, controllo superato |
| Giudizio | troppo complicato, suoni non calibrati, strumenti da scegliere meglio |

## 2. Suono e semplicità
| | |
|---|---|
| Cause | strumenti estratti a caso (anche senza batteria o basso), timbri casuali nello stile, parole di revisione di altri generi, due LoRA fuori genere |
| Intervento | organico curato per i 39 generi, compositore semplificato |
| Misura | ripetizione mediana 43% |
| Prove | «Ruggito Sospeso»: 207 s su 210, controllo superato |
| Giudizio | fraseggi, melodie e accordi sembrano scritti da un'intelligenza artificiale |

## 3. Composizione
| | |
|---|---|
| Cause | melodie a passi casuali, giri di quattro battute senza cadenze, nessun anticipo |
| Ricerca | [skill, studi e raccolte](../ricerche/2026-11-28-composizione.md) |
| Intervento | armonia per periodi, melodia da scheletro e motivi ([progetto](../superpowers/specs/2026-11-28-composizione-design.md)) |
| Misure (208 spartiti di prova) | ripetizione mediana 39%, 100 cambi di accordo, durata entro l'1%, note dell'accordo sui tempi forti 92% (mediana) |
| Test | 214 superati al momento della pubblicazione |
| Prova | un hard rock richiesto alle 16:37 UTC, in produzione alla stesura di questo report |
| Giudizio | in attesa dell'ascolto |

## Cosa non è verificato
- La qualità all'ascolto: le misure dicono solo che le regole di scrittura sono rispettate.
- Quanto fedelmente YuE2 renda spartito, strumenti e timbri.
- Gli organici dei generi non ancora ascoltati.
- Mastering e parametri audio del motore: non modificati.
